Student Hub Portal

Student Hub Portal is a simple web application developed for college students. It provides information about courses, attendance, assignments, faculty members, notices, and student profiles.


This project is created using HTML5 and CSS3 for academic practical purposes. It helps students access important academic information through a simple and user-friendly interface.
